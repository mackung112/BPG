หากต้องการยกเลิกการกรองข้อมูลทั้งหมดของ Slicer ตัวใดตัวหนึ่งเพื่อให้ยอดใน Dashboard กลับมารายงานค่าสรุปทั้งหมดตามเดิม ต้องกดปุ่มใดบนตัว Slicer?{
=ปุ่มไอคอนรูปกรวยกรองข้อมูลที่มีเครื่องหมายกากบาทสีแดงกำกับอยู่ขอบบนขวาของ Slicer (Clear Filter)
~ปุ่มกากบาทสีดำมุมซ้ายบนของหน้าต่างโปรแกรม Microsoft Excel
~คลิกขวาที่ตัวปุ่มแล้วเลือกเมนู "Delete Data Filter connection" เพื่อปิดสัญญาณกรอง
~ดับเบิ้ลคลิกปุ่ม Slicer นั้นติดต่อกันเพื่อบังคับส่งชุดคำสั่งรีเซ็ตค่าของสูตรอ้างอิง
}

// อ้างอิงจากหลักสูตร "Microsoft Excel – Data Analytics 101 Using Excel"
ข้อดีของเครื่องมือ "Power Query" ที่ตอบโจทย์การประหยัดเวลาการทำซ้ำในงาน Dashboard รายสัปดาห์คืออะไร?{
=ช่วยบันทึกทุกขั้นตอนการทำงาน (Applied Steps) อย่างเช่นการคลีนข้อมูล ลบคอลัมน์ และการแปลงข้อมูลเอาไว้ ทำให้การอัปเดตสถิติในรอบถัดไปทำได้แค่คลิกปุ่ม Refresh เดียว
~ช่วยจำลองการคำนวณวิจัยสถิติพยากรณ์ล่วงหน้า 5 ปีให้เสร็จสิ้นได้รวดเร็วทันใจกว่าการเปิดตาราง PivotTable
~ช่วยแก้ไขสูตรคำนวณที่พิมพ์สะกดผิดบนแถวให้มีความถูกต้องตามหลักไวยากรณ์โดยอัตโนมัติ
~มีโมเดลปัญญาประดิษฐ์ตรวจสแกนหน้าตาความสวยงามของเฉดสีบน Dashboard และให้ข้อวิจารณ์ประเมินระดับความงาม
}

// อ้างอิงจากคู่มือหลักสูตร "Excel Advance Functions"
ในการจัดการวัตถุข้อมูลบน Dashboard ขีดจำกัดของการใช้งานกล่องรายการดรอปดาวน์ (Drop-down List) ที่สร้างจาก Data Validation เมื่อนำมาเทียบกับ Slicer คือข้อใด?{
=ป้อนข้อมูลได้ทีละหนึ่งตัวเลือก ไม่เห็นรายการตัวเลือกแสดงอยู่ลอยตัวตลอดเวลา และไม่สามารถเชื่อมต่อโดยตรงเพื่อเปลี่ยนโครงสร้าง PivotChart ได้ง่ายในคลิกเดียว
~ไม่รองรับข้อมูลประเภทวันที่และเวลาจำหน่ายและต้องเขียนสูตร VBA ซับซ้อนควบคุมตลอดทุกการใช้งาน
~ทำให้การคำนวณสูตรสืบค้นอย่าง XLOOKUP ในแผ่นงานอื่นๆ ล่าช้าและส่งผลให้ขนาดไฟล์ของ Excel บวมโตผิดปกติ
~ไม่สามารถแสดงผลบนแผ่นงานที่มีการซ่อนเส้นแบ่งตาราง Gridlines เอาไว้ได้
}

// อ้างอิงจากบทความ "วิธีออกแบบ Dashboard ให้ดูมืออาชีพใน Excel 365"
สิ่งใดต่อไปนี้คือหัวใจสำคัญในการทำหน้า Dashboard ธุรกิจให้ "มีชีวิต" และสร้าง "ความคุ้มค่าต่องานวางแผนบริหารองค์กร"?{
=ระบบอัปเดตข้อมูลแบบกึ่งอัตโนมัติหรืออัตโนมัติที่เชื่อมประสานได้อย่างเป็นระบบ และสามารถแปลงข้อมูลเป็นข้อมูลที่นำไปสู่การตัดสินใจและแก้ปัญหาได้ทันที
~การประดับภาพกราฟิกสวยงามและใส่แผนภูมิรูปแบบ 3D จำนวนมากเพื่อสร้างความสวยงามหรูหราให้หน้าเอกสารส่งออก
~ความจุของข้อมูลดิบที่อัดแน่นหลายล้านแถวแสดงอยู่บนหน้าหลักเพื่อให้ผู้บริหารใช้นั่งสแกนหาตัวเลขแบบรายบรรทัด
~การล็อกหน้าจอทั้งหมดไม่ให้ผู้ใช้งานทั่วไปปรับเปลี่ยนการกรองหรือเลือกดูสถิติในมิติส่วนบุคคลได้เลย
}
