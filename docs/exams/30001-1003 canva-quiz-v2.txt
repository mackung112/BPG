ในโปรแกรม Canva สำหรับผู้ใช้งานที่เพิ่งเริ่มต้นเข้าใช้งานครั้งแรกเพื่อเริ่มสร้างสไลด์ วิธีการสมัครเข้าใช้งานระบบวิธีใดที่แนะนำว่าสะดวกรวดเร็วที่สุด?{
=ลงชื่อเข้าใช้งานด้วยบัญชี Google (Sign in with Google)
~กรอกข้อมูลสมัครด้วยเบอร์โทรศัพท์บ้าน
~ส่งหนังสือคำขอรับรหัสผ่านทางอีเมลบริษัท
~กรอกเลขประจำตัวประชาชน 13 หลัก
}

ในโปรแกรม Canva หากเลือกใช้แม่แบบ (Templates) หรือองค์ประกอบที่มีสัญลักษณ์รูป "มงกุฎสีส้ม" (หรือสัญลักษณ์ Pro) หมายถึงเงื่อนไขการใช้งานข้อใด?{
=เป็นเทมเพลตสำหรับผู้ใช้งาน Canva Pro ซึ่งอาจมีค่าใช้จ่ายเพิ่มเติมหากใช้บัญชีฟรี
~เป็นเทมเพลตที่แจกฟรีสำหรับทุกคนโดยไม่มีข้อกำหนดใดๆ
~เป็นเทมเพลตที่อนุญาตเฉพาะหน่วยงานราชการใช้งานเท่านั้น
~เป็นแม่แบบที่ปิดปรับปรุงชั่วคราวและไม่สามารถเลือกได้
}

โครงสร้างส่วนติดต่อผู้ใช้งาน (Interface) ในโปรแกรม Canva ข้อใดอธิบายตำแหน่งของพื้นที่ทำงานหลัก (Workspace) และแถบเครื่องมือปรับแต่งได้ถูกต้อง?{
=พื้นที่ทำงานหลักอยู่ตรงกลาง, แผงเลือกวัตถุอยู่ด้านซ้าย, แถบปรับแต่งตัวเลือกเฉพาะอยู่ด้านบน
~พื้นที่ทำงานหลักอยู่ด้านซ้าย, แผงเลือกวัตถุอยู่ด้านบน, แถบปรับแต่งตัวเลือกเฉพาะอยู่ตรงกลาง
~พื้นที่ทำงานหลักอยู่ด้านบน, แผงเลือกวัตถุอยู่ตรงกลาง, แถบปรับแต่งตัวเลือกเฉพาะอยู่ด้านซ้าย
~พื้นที่ทำงานหลักอยู่ด้านล่าง, แผงเลือกวัตถุอยู่ด้านขวา, แถบปรับแต่งตัวเลือกเฉพาะอยู่ด้านบน
}

ปุ่มลัด (Shortcut Key) บนคีย์บอร์ดที่สามารถกดเมื่อทำงานในโปรแกรม Canva เพื่อสร้างกล่องข้อความพิมพ์ตัวหนังสือ (Text Box) ขึ้นมาบนสไลด์ทันทีคือปุ่มใด?{
=T
~M
~P
~X
}

ในโปรแกรม Canva หากต้องการตัดรูปภาพคนหรือสินค้าให้อยู่ในกรอบรูปทรงเรขาคณิต เช่น ทรงกลม เพื่อให้งานดีไซน์สวยงาม ควรเลือกใช้เครื่องมือใดในกลุ่ม Elements?{
=Frame (กรอบรูป)
~Grid (ตารางรูป)
~Shape (รูปทรงทั่วไป)
~Border (เส้นขอบ)
}

ขั้นตอนการนำรูปถ่ายใส่ลงไปในกรอบรูป (Frame) ในโปรแกรม Canva ข้อใดต่อไปนี้อธิบายการทำงานได้ถูกต้องและรวดเร็วที่สุด?{
=คลิกลากรูปภาพที่ต้องการมาวางทับไว้บนกรอบรูปนั้นโดยตรงแล้วปล่อยเมาส์
~ดับเบิลคลิกที่รูปภาพแล้วพิมพ์ชื่อเฟรมที่ต้องการใส่
~ใช้เครื่องมือครอบตัดเพื่อแต่งขอบรูปภาพก่อนลากมาวาง
~กดปุ่ม Ctrl + C แล้วไปคลิกขวาที่เฟรมเพื่อสั่ง Paste Special
}

ในโปรแกรม Canva หากรูปภาพที่ลากเข้าไปใส่ในกรอบรูป (Frame) มีตำแหน่งหรือสเกลรูปภาพด้านในที่ไม่พอดี สามารถเข้าไปปรับย้ายตำแหน่งหรือขนาดภาพข้างในเฟรมได้อย่างไร?{
=ดับเบิลคลิก (Double-click) ที่กรอบเฟรมเพื่อเปิดโหมดปรับแต่งรูปภาพภายใน
~ไม่สามารถปรับแก้ไขได้ ต้องลบเฟรมแล้วทำใหม่เท่านั้น
~คลิกเลือกปุ่ม Crop บนแถบเครื่องมือด้านล่างหน้าจอ
~กดปุ่ม Ctrl + Z ค้างไว้ในขณะลากขยายขอบภาพ
}

ในโปรแกรม Canva การตัดรูปภาพ (Crop) บางส่วนที่ไม่ต้องการออกไปจากขอบภาพภายนอก สามารถทำได้อย่างรวดเร็วอย่างไรเมื่อคลิกที่ตัวรูปภาพ?{
=ลากปุ่มแฮนเดิลที่เป็นขอบสีขาวตรงด้านข้างหรือมุมภาพเข้ามาตามขนาดที่ต้องการ
~พิมพ์ขนาดสัดส่วนที่ต้องการในแท็บ Alignment
~คลิกขวาที่รูปภาพแล้วพิมพ์ความสูงความกว้างเป็นพิกเซล
~ใช้ยางลบวาดทับบริเวณด้านหลังภาพเพื่อลบออก
}

ในโปรแกรม Canva หากต้องการจัดกลุ่มวัตถุต่างๆ เช่น ภาพ วงกลม และตัวอักษร ให้อยู่รวมกันเพื่อให้เคลื่อนย้ายไปพร้อมๆ กันอย่างสะดวก จะต้องเลือกใช้คำสั่งใด?{
=Group (จัดกลุ่ม)
~Align to Page
~Lock Elements
~Position Grid
}

เมื่อจัดตำแหน่งวัตถุในโปรแกรม Canva แล้วมีข้อความสีขาวโดนรูปภาพบังอยู่ด้านหลัง หากต้องการย้ายตัวอักษรขึ้นมาอยู่เหนือวัตถุอื่นๆ จะต้องเข้าไปตั้งค่าในเมนูใด?{
=Position (ตำแหน่ง) > เลือกระดับเลเยอร์หรือกด Bring to Front
~Animate (แอนิเมชัน) > เลือกเลเยอร์ข้อความ
~Flip (กลับด้าน) > เลือกทิศทางบน-ล่าง
~Transparency (ความโปร่งใส) > ปรับค่าเป็นศูนย์
}

ในโปรแกรม Canva หากต้องการใส่รูปภาพสติกเกอร์ ภาพกราฟิกน่ารักๆ หรือลายเส้นเสริมสร้างจุดเด่นให้สไลด์งานนำเสนอ จะต้องเข้าไปเลือกคำสั่งในแถบเครื่องมือใด?{
=Elements (องค์ประกอบ)
~Uploads (อัปโหลด)
~Designs (การออกแบบ)
~Text (ข้อความ)
}

การส่งออกผลงาน (Export) ในโปรแกรม Canva หากเป้าหมายคือการนำไฟล์ไปพิมพ์ลงกระดาษจริงเพื่อเป็นแผ่นพับหรือเอกสารสรุป ควรดาวน์โหลดไฟล์ในนามสกุลข้อใด?{
=PDF Print
~MP4 Video
~PNG High Quality
~SVG Vector Graphics
}

หากผู้เรียนต้องการเซฟงานออกแบบในโปรแกรม Canva นำไปใช้โพสต์บนโซเชียลมีเดียอย่าง Facebook หรือ Instagram เพื่อให้ได้ภาพที่คมชัดและสีสันสวยงามมากที่สุด ควรเลือกประเภทไฟล์รูปแบบใดตอนดาวน์โหลด?{
=PNG
~GIF
~PPTX
~PDF Standard
}

ปุ่มลัดบนคีย์บอร์ดปุ่มใดเมื่อกดขณะทำงานในโปรแกรม Canva แล้วจะปรากฏรูปทรง "สี่เหลี่ยม" (Rectangle) ขึ้นมาบนพื้นที่ดีไซน์ทันที?{
=R
~S
~B
~L
}

ปุ่มลัดบนคีย์บอร์ดปุ่มใดเมื่อกดขณะทำงานในโปรแกรม Canva แล้วจะปรากฏรูปทรง "วงกลม" (Circle) ขึ้นมาบนสไลด์ดีไซน์ทันที?{
=C
~O
~W
~G
}

ปุ่มลัดสากลบนคีย์บอร์ดข้อใดในโปรแกรม Canva ที่ใช้สำหรับการย้อนกลับไปยกเลิกการทำงานหรือการแก้ไขที่ผิดพลาดล่าสุด (Undo)?{
=Ctrl + Z (หรือ Cmd + Z บน Mac)
~Ctrl + Y (หรือ Cmd + Y บน Mac)
~Ctrl + C (หรือ Cmd + C บน Mac)
~Ctrl + V (หรือ Cmd + V บน Mac)
}

ในโปรแกรม Canva การเปลี่ยนสีฟอนต์ตัวหนังสือและการเปลี่ยนสีวัตถุกราฟิก สามารถทำได้โดยผ่านการคลิกเลือกเครื่องมือสีจากส่วนใดของหน้าจอ?{
=แถบเมนูตัวเลือกเฉพาะที่จะปรากฏขึ้นที่ด้านบนหลังจากคลิกเลือกตัววัตถุแล้ว
~แผงตัวเลือกด้านล่างที่อยู่ใต้พื้นที่แสดงสไลด์ย่อยทั้งหมด
~แถบเมนูด้านซ้ายสุดในหมวดหมู่ Brand Kit เท่านั้น
~หน้าต่างสป็อปอัปที่เปิดขึ้นโดยกดปุ่ม Ctrl + Alt + Delete
}

ประโยชน์ที่โดดเด่นและสำคัญที่สุดของฟังก์ชัน "Templates" (เทมเพลต) ในโปรแกรม Canva ที่เอื้อต่อผู้ใช้งานมือใหม่คือข้อใด?{
=ช่วยประหยัดเวลาและพลังสร้างสรรค์ด้วยโครงสร้างเลย์เอาต์และการจับคู่สีที่นักออกแบบดีไซน์ไว้พร้อมใช้แล้ว
~ช่วยให้ระบบคอมพิวเตอร์ประมวลผลวิดีโอได้เร็วขึ้น 3 เท่า
~ช่วยตรวจสอบหลักไวยากรณ์ภาษาต่างประเทศให้อัตโนมัติในช่องข้อความ
~ป้องกันไม่ให้เกิดการแก้ไขข้อมูลโดยไม่ได้รับอนุญาตจากเจ้าของเครื่อง
}

ในโปรแกรม Canva หากออกแบบงานนำเสนอเรียบร้อยและต้องการส่งมอบงานในรูปแบบลิงก์ออนไลน์เพื่อให้ผู้อื่นสามารถกดเข้ามาดูงานหรือร่วมกันแก้ไขงานแบบเรียลไทม์ได้ จะต้องเลือกทำอย่างไร?{
=คลิกปุ่ม Share (แชร์) > ตั้งค่าลิงก์เป็น Anyone with the link > เลือกสิทธิ์ Can view หรือ Can edit
~กดปุ่ม Download แล้วแชร์ไฟล์เข้าโปรแกรมส่งอีเมลแบบเขียนลงแผ่น CD
~พิมพ์ชื่อบัญชีผู้ใช้ออกมาแล้วส่งทางจดหมายกระดาษ
~คลิกปุ่ม File > เลือก Export to USB Flash Drive
}
