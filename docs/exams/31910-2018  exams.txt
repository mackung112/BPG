// ข้อที่ 1

=การใช้สื่อหลายประเภท เช่น ข้อความ ภาพนิ่ง เสียง ภาพเคลื่อนไหว และวิดีโอ ผสมผสานร่วมกับระบบตอบโต้ (Interactive)
~การแปลงเอกสารกระดาษเป็นไฟล์ PDF
~การพิมพ์งานด้วยโปรแกรมประมวลคำ
~การส่งอีเมลธุรกิจผ่านเครือข่ายอินเทอร์เน็ต
}

// ข้อที่ 2
สื่อชนิดใดที่จัดเป็น "สื่อประเภทเรียบง่าย" (Classic Media) ตามหลักการนําเสนอข้อมูล?{
=สื่อสิ่งพิมพ์ (เช่น หนังสือ, โปสเตอร์, แผ่นพับ)
~ภาพยนตร์ 3 มิติเชิงปฏิบัติสัมพันธ์
~พ็อดคาสต์ออนไลน์
~เว็บไซต์ข่าวสารแบบตอบโต้
}

// ข้อที่ 3
องค์ประกอบใดในสื่อมัลติมีเดียที่ใช้ประสาทสัมผัสในการได้ยิน และมีเสียงบรรยาย/ดนตรีช่วยให้สื่อมีความน่าสนใจกว่าตัวหนังสือเพียงอย่างเดียว?{
=เสียง (Sound)
~ข้อความ (Text)
~ภาพกราฟิก (Graphic)
~วีดิโอ (Video)
}

// ข้อที่ 4
สื่อประเภท "ภาพกราฟิก" (Graphic) มีข้อดีโดดเด่นอย่างไรเมื่อเทียบกับข้อความ?{
=สามารถสรุปข้อมูลต่าง ๆ ออกมาเป็นรูปภาพที่มีศักยภาพการสื่อสารได้ดีในเวลาที่จำกัด
~สามารถเก็บข้อมูลบทสนทนายาว ๆ ได้สมบูรณ์ที่สุดในทุกมิติ
~สามารถเล่นเสียงและภาพเคลื่อนไหวได้พร้อมกันโดยธรรมชาติของไฟล์
~ประหยัดทรัพยากรการแสดงผลมากกว่าข้อความแบบอักษรดิบ
}

// ข้อที่ 5
ข้อใดกล่าวถูกต้องที่สุดเกี่ยวกับ "วิดีโอ" (Video) ในเทคโนโลยีมัลติมีเดีย?{
=สามารถแสดงผลได้ทั้งภาพเคลื่อนไหวและเสียงไปพร้อมกัน ทำให้เกิดความน่าสนใจในการนำเสนอ
~เป็นสื่อที่ไม่ต้องการเครื่องเล่น (Player) หรือระบบแสดงผลใด ๆ
~เหมาะสำหรับการบรรจุเนื้อหาจำนวนมากและละเอียดที่สุดโดยไม่ต้องคัดกรองเนื้อหา
~ไม่สนับสนุนระบบภาพเคลื่อนไหว มีเพียงเสียงประกอบเท่านั้น
}

// ข้อที่ 6
ในการวางแผนผลิตสื่อ จิตวิทยาเข้ามาเกี่ยวข้องอย่างไรในการออกแบบสื่อนําเสนอ?{
=ช่วยวิเคราะห์พฤติกรรม ทัศนคติ และความคาดหวังของผู้รับสาร เพื่อให้เกิดการยอมรับและพึงพอใจในเนื้อหา
~ช่วยคำนวณอัตราความเร็วของระบบเครือข่ายคอมพิวเตอร์
~ช่วยประเมินแรงดันไฟฟ้าของฮาร์ดแวร์ในการเรนเดอร์งานวิดีโอ
~ช่วยป้องกันการถูกละเมิดสิทธิ์โดยโปรแกรมตัดต่ออัตโนมัติ
}

// ข้อที่ 7
"คุณลักษณะผู้รับสาร" (Audience Profile) ข้อใดที่ผู้สร้างสรรค์สื่อจำเป็นต้องวิเคราะห์เพื่อให้สื่อสารอย่างมีประสิทธิภาพสูงสุด?{
=ช่วงวัย, หน้าที่การงาน, ประสบการณ์, และระดับการศึกษา
~ยอดเงินคงเหลือในบัญชีและการซื้อของออนไลน์
~ความเร็วของการเชื่อมต่ออินเทอร์เน็ตสูงสุดของผู้ให้บริการ
~ยี่ห้อสมาร์ทโฟนที่ใช้งานและจำนวนแอปตัดต่อในเครื่อง
}

// ข้อที่ 8
หากผู้นำเสนอต้องการสร้างการรับรู้หรืออารมณ์ร่วมให้เกิดขึ้นกับผู้ชม สิ่งแรกที่ต้องทำตามหลักการวางแผนสื่อคืออะไร?{
=วิเคราะห์และกำหนดจุดมุ่งหมายในการนำเสนอไม่ให้มีหลายประเด็นเกินไปจนเกิดความคลุมเครือ
~จัดสเปกเครื่องคอมพิวเตอร์ขั้นต่ำด้วย Pentium 4
~ส่งสไลด์ให้ผู้เชี่ยวชาญตรวจสอบลิขสิทธิ์เพลงประกอบทันที
~ทำการอัปโหลดวิดีโอสคริปต์ทั้งหมดขึ้น Web Server ทันที
}

// ข้อที่ 9
สื่อประเภทใดในปัจจุบันที่ได้รับความนิยมในการประยุกต์ใช้เพื่อความสัมฤทธิผลสูงสุดผ่านการทำงานผสานบูรณาการระหว่างข้อความ ภาพนิ่ง ภาพเคลื่อนไหว และเสียง?{

// ข้อที่ 10
การนำองค์ประกอบต่าง ๆ มาแสดงผลผสมผสานกันโดยใช้คอมพิวเตอร์เป็นตัวหลักในการสร้างสรรค์ มีประโยชน์ต่อการสื่อสารอย่างไร?{
=ช่วยสร้างความประทับใจและความเข้าใจข้อมูลได้เป็นอย่างดี

~ช่วยลดจำนวนเทค (Take) ในกระบวนการถ่ายทำให้เหลือหนึ่งเทคเสมอ
~ป้องกันเนื้อหาไม่ให้ถูกแชร์ลงบนสื่อสังคมออนไลน์อื่น ๆ
}

// ข้อที่ 11
การพิจารณาเลือกใช้สื่อและการออกแบบเนื้อหาให้ตอบสนองกลุ่มเป้าหมายได้หลากหลายวาระ เช่น สื่อสำหรับเด็ก หรือ สื่อสำหรับสถาปนิก ต้องอาศัยความเข้าใจพื้นฐานในเรื่องใด?{
=ความเข้าใจพื้นฐานการรับรู้และข้อจำกัดของผู้รับชมแต่ละกลุ่ม รวมถึงความเหมาะสมของสื่อแต่ละชนิด
~การเลือกแอปพลิเคชัน YouCut บนระบบ iOS เท่านั้น
~การติดตั้งระบบฐานข้อมูล MySQL 5.0 บนเว็บเซิร์ฟเวอร์
~การแปลงไฟล์เสียงประกอบเป็นสกุล .wav ทุกครั้งก่อนอัปโหลด
}

// ข้อที่ 12
ข้อใดเป็นหนึ่งในสื่อนำเสนอข้อมูลสารสนเทศ 4 ประเภทที่ใช้ร่วมกันในโครงการวิจัยลุ่มน้ำทะเลสาบสงขลา?{
=สื่อสิ่งพิมพ์ประเภทโปสเตอร์ สื่อวีดีทัศน์ สื่อเว็บไซต์ และสื่อหนังสืออิเลคทรอนิคส์
~สื่อวิทยุกระจายเสียง สื่อโทรทัศน์ดาวเทียม สื่อหนังสือพิมพ์รายวัน และสื่อแผ่นพับขาวดำ
~สื่อภาพยนตร์ 3 มิติ สื่อวิทยุชุมชน สื่อแผ่นเสียง และสื่อเอกสารอ้างอิงโบราณ
~สื่อจัดนิทรรศการถาวร สื่อหนังสือพิมพ์ สื่อนิตยสารแฟชั่น และสื่อภาพสไลด์โชว์
}

// ข้อที่ 13
