หากต้องการรวมเซลล์หลายๆ เซลล์ที่เลือกให้เป็นเซลล์เดียว พร้อมกับจัดรูปข้อความให้อยู่กึ่งกลางกลุ่มเซลล์นั้นทันที ในโปรแกรม Microsoft Excel ควรเลือกใช้คำสั่งใด?{
=Merge & Center
~Wrap Text
~Align Center
~Format Cells
}

หากต้องการเน้นหัวตาราง (Column Header) ในโปรแกรม Microsoft Excel ให้มีความชัดเจนและแยกออกจากข้อมูลปกติด้วยการเทสีพื้นหลังของเซลล์ ต้องใช้เครื่องมือใดในแท็บ Home?{
=Fill Color
~Font Color
~Borders
~Cell Styles
}

ในการจัดระเบียบข้อมูลตัวเลขรหัสสินค้าหรือสถานะในโปรแกรม Microsoft Excel ให้ดูเรียบร้อย การจัดให้ข้อมูลอยู่ตรงกลางของเซลล์ทั้งในแนวตั้งและแนวนอน ต้องใช้กลุ่มคำสั่งใดในแท็บ Home?{
=Alignment
~Number
~Font
~Styles
}

เมื่อเราพิมพ์ข้อมูลลงในตารางแล้วพิมพ์เอกสารออกมาทางเครื่องพิมพ์ หากไม่ได้ตั้งค่าใดๆ เส้นตารางจางๆ (Gridlines) ในโปรแกรม Microsoft Excel จะไม่แสดงผล หากต้องการให้ตารางมีเส้นขอบที่ชัดเจนต้องเลือกใช้คำสั่งใด?{
=Borders
~Gridlines Active
~Draw Table
~Outline Color
}

สูตรหรือฟังก์ชันใดในโปรแกรม Microsoft Excel ใช้สำหรับหาผลรวมของข้อมูลตัวเลขในกลุ่มเซลล์ที่ต้องการ เช่น ตั้งแต่เซลล์ B2 ถึง B10?{
==SUM(B2:B10)
~=TOTAL(B2:B10)
~=ADD(B2:B10)
~=SUMMARY(B2:B10)
}

ฟังก์ชันใดในโปรแกรม Microsoft Excel ที่ใช้ในการคำนวณหาค่าเฉลี่ยของคะแนนสอบของนักเรียนทั้งหมดในคลาส?{
==AVERAGE(C2:C20)
~=MEAN(C2:C20)
~=AVG(C2:C20)
~=MEDIAN(C2:C20)
}

หากต้องการหาว่าพนักงานคนใดมียอดขายสูงสุด (หาค่าตัวเลขที่มากที่สุดในแถวข้อมูล) ในโปรแกรม Microsoft Excel ต้องใช้ฟังก์ชันใด?{
==MAX(D2:D15)
~=HIGH(D2:D15)
~=LARGE(D2:D15)
~=TOP(D2:D15)
}

ฟังก์ชันใดในโปรแกรม Microsoft Excel ใช้สำหรับตรวจสอบหาค่าใช้จ่ายที่ต่ำที่สุดในงบประมาณประจำปี?{
==MIN(E2:E30)
~=LOW(E2:E30)
~=SMALL(E2:E30)
~=BOTTOM(E2:E30)
}

ฟังก์ชันใดในโปรแกรม Microsoft Excel ที่ใช้นับจำนวนเซลล์ที่มีเฉพาะข้อมูลตัวเลขเท่านั้นในกลุ่มเซลล์ที่กำหนด?{
==COUNT(A1:A50)
~=COUNTA(A1:A50)
~=COUNTBLANK(A1:A50)
~=NUMBERCOUNT(A1:A50)
}

หากต้องการนับจำนวนรายชื่อของพนักงานที่ลงชื่อเข้างาน (ซึ่งข้อมูลเป็นข้อความตัวอักษรและต้องการนับเซลล์ที่ไม่ว่างทั้งหมด) ในโปรแกรม Microsoft Excel ควรเลือกใช้ฟังก์ชันใด?{
==COUNTA(B2:B100)
~=COUNT(B2:B100)
~=COUNTIF(B2:B100)
~=SUM(B2:B100)
}

หากต้องการสร้างเครื่องมือวิเคราะห์และสรุปผลข้อมูลจำนวนมากๆ ได้อย่างรวดเร็วและยืดหยุ่นในโปรแกรม Microsoft Excel ควรเลือกใช้เครื่องมือใดตามคำแนะนำของ Thep Excel?{
=Pivot Table
~VLOOKUP
~Data Validation
~Conditional Formatting
}

ในเครื่องมือ Pivot Table ของโปรแกรม Microsoft Excel ส่วน Layout Area ใดที่ใช้สําหรับการกรองข้อมูลเพื่อดูข้อมูลเฉพาะส่วนย่อย เช่น คัดกรองตามภูมิภาค?{
=Filters
~Rows
~Columns
~Values
}

ในพื้นที่การทำงานของ Pivot Table ในโปรแกรม Microsoft Excel หากต้องการแบ่งกลุ่มข้อมูลสินค้าให้แสดงรายการลงมาในแนวนอนทีละบรรทัด ควรลากฟิลด์ข้อมูลไปวางในส่วนใด?{
=Rows
~Columns
~Values
~Filters
}

การจัดเรียงหัวข้อหรือฟิลด์ข้อมูลในเครื่องมือ Pivot Table ในโปรแกรม Microsoft Excel เพื่อเปรียบเทียบข้อมูลแบบสองมิติเป็นแนวนอนจากซ้ายไปขวา ควรลากฟิลด์นั้นไปไว้ในส่วนใด?{
=Columns
~Rows
~Values
~Filters
}

พื้นที่จัดวาง "Values" ในระบบโครงสร้างของ Pivot Table ในโปรแกรม Microsoft Excel มีเป้าหมายสําคัญเพื่ออะไร?{
=การระบุค่าตัวเลขที่ต้องการประมวลผลคำนวณ เช่น ยอดขายรวม หรือ จำนวนรายการ
~การแบ่งกลุ่มชื่อข้อมูลในแนวนอน
~การคัดกรองข้อมูลทั้งหมด
~การจัดรูปแบบสีและดีไซน์ของตารางข้อมูล
}

หากผู้เรียนต้องการแก้ไขฟังก์ชันการคำนวณในช่อง Values ของ Pivot Table ในโปรแกรม Microsoft Excel จากฟังก์ชัน SUM เป็นฟังก์ชัน AVERAGE ต้องทำผ่านคำสั่งใด?{
=Value Field Settings
~Format Cells
~PivotTable Options
~Design Layout
}

เมื่อข้อมูลในตารางหลัก (Source Data) ในโปรแกรม Microsoft Excel มีการเปลี่ยนแปลง ข้อมูลใน Pivot Table จะไม่อัปเดตทันที ผู้ใช้งานจะต้องทำการคลิกขวาที่ Pivot Table แล้วกดคำสั่งใด?{
=Refresh
~Recalculate
~Update Table
~Reset Data
}

ตามแนวทางการทำงานร่วมกับ AI ในโปรแกรม Microsoft Excel ปี 2026 บทบาทของ AI แบบ Advisor Chatbot (เช่น Copilot หรือ ChatGPT) มีประโยชน์อย่างไรในการใช้สูตร?{
=ช่วยแนะแนวทางการเขียนสูตรและอธิบายความหมาย แต่ผู้ใช้ต้องตรวจสอบความถูกต้องเชิงตรรกะด้วยตนเอง
~สามารถแก้สมการสูตรให้ถูกต้องได้ 100% เสมอโดยไม่ต้องตรวจทาน
~ใช้เขียนฟังก์ชันที่ซับซ้อนและรันให้อัตโนมัติทันทีโดยไม่ต้องเชื่อมต่อข้อมูล
~ทำหน้าที่ตรวจสอบและค้ำประกันข้อมูลทางบัญชีให้โดยกฎหมายรองรับ
}

ข้อใดคือลักษณะสำคัญของโหมด "In-cell Generative Functions" ในการใช้ AI ร่วมกับโปรแกรม Microsoft Excel เพื่อทำงาน?{
=การเรียกใช้สูตรคำสั่งที่ส่งค่าไปยังระบบ AI แล้วตอบกลับเป็นข้อความภายในเซลล์นั้นโดยตรง
~การให้ AI เข้าควบคุมการเคลื่อนที่ของเมาส์และแป้นพิมพ์ในการเขียนสูตร
~การเชื่อมโยงข้อมูลไฟล์ Excel ข้ามเครือข่ายอินเทอร์เน็ตโดยไม่ใช้ฟังก์ชันคำนวณ
~การสร้างปุ่มมาโคร (Macro) เพื่อเปิดโปรแกรมเสริมอื่นๆ นอกเหนือจาก Excel
}

ข้อดีที่เด่นชัดที่สุดของการใช้งาน Pivot Table ในโปรแกรม Microsoft Excel เมื่อเปรียบเทียบกับการเขียนสูตรคำนวณแบบเดิมคือข้อใด?{
=ช่วยให้วิเคราะห์ข้อมูลจำนวนมากได้รวดเร็ว ปรับเปลี่ยนมุมมองได้ง่ายโดยไม่ต้องเขียนสูตรที่ซับซ้อน
~ช่วยเพิ่มประสิทธิภาพให้คอมพิวเตอร์ทำงานคำนวณได้เร็วขึ้น 2 เท่า
~ป้องกันข้อมูลสูญหายและสำรองข้อมูลขึ้นระบบคลาวด์ให้อัตโนมัติ
~ทำให้ไฟล์ Excel สามารถเปิดทำงานได้ในโปรแกรมระบบอื่นโดยไม่มีลิขสิทธิ์
}
