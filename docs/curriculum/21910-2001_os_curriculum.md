# ระบบปฏิบัติการคอมพิวเตอร์ (21910-2001)
สัปดาห์ที่ 10: ฮาร์ดแวร์และการจัดการไดร์เวอร์ผ่านระบบ Device Manager ✅
การเรียกใช้งาน Device Manager ใน Windows
การอ่านค่าสถานะและสัญลักษณ์แจ้งเตือนความผิดปกติของอุปกรณ์
การค้นหา Hardware ID เพื่อระบุอุปกรณ์ที่ไม่มีไดร์เวอร์ (Unknown Device)
การดาวน์โหลดและติดตั้งไดร์เวอร์อย่างปลอดภัยจากเว็บไซต์ผู้ผลิตฮาร์ดแวร์
การใช้คำสั่ง Rollback Driver เพื่อย้อนกลับเมื่อการอัปเดตทำให้ระบบมีปัญหา
## Unit 11: โปรแกรมยูทิลิตี้สำหรับการวิเคราะห์และซ่อมแซมไฟล์ระบบพื้นฐาน (ทำจบที่สัปดาห์ที่ 11)

- 11.1 การเปิดใช้งาน Command Prompt ด้วยสิทธิ์ผู้ดูแลระบบ (Administrator)
- 11.2 การพิมพ์และรันคำสั่ง System File Checker (sfc /scannow)
- 11.3 การวิเคราะห์ความหมายของผลลัพธ์จากการสแกนตรวจสอบไฟล์ระบบ
- 11.4 การใช้คำสั่ง Check Disk (chkdsk) เพื่อวิเคราะห์ความผิดปกติของฮาร์ดดิสก์
- 11.5 การอ่านค่าการทำงานของ CPU, RAM และ Disk ผ่าน Task Manager
สัปดาห์ที่ 12: โปรแกรมยูทิลิตี้สำหรับการจัดการพื้นที่และเพิ่มประสิทธิภาพการทำงาน
การเรียกใช้งาน Disk Cleanup เพื่อลบไฟล์ขยะและไฟล์ชั่วคราวอย่างปลอดภัย
การใช้ตัวเลือก System Files ใน Disk Cleanup เพื่อลบไฟล์อัปเดตเก่าของ Windows
หลักการทำงานและการใช้งาน Disk Defragmenter (สำหรับคอมพิวเตอร์ที่ใช้ฮาร์ดดิสก์แบบจานหมุน)
การปิดโปรแกรมที่เปิดขึ้นมาพร้อมเครื่อง (Startup Programs) เพื่อลดการใช้ RAM
การปรับแต่ง Visual Effects เพื่อลดภาระการประมวลผลของเครื่องเก่า
สัปดาห์ที่ 13: ไวรัสคอมพิวเตอร์และการตั้งค่าระบบความปลอดภัยเบื้องต้น
ความหมายและพฤติกรรมของมัลแวร์ประเภทต่างๆ (Virus, Worm, Trojan, Ransomware)
การเปิดใช้งานและตรวจสอบสถานะการอัปเดตของ Windows Security
การตั้งค่าการสแกนระบบแบบรวดเร็ว (Quick Scan) และแบบละเอียด (Full Scan)
การจัดการไฟล์ต้องสงสัยที่ถูกระบบกักกันไว้ (Quarantine)
การอนุญาตหรือบล็อกโปรแกรมผ่านระบบ Windows Defender Firewall
สัปดาห์ที่ 14: การสำรองข้อมูลและการกู้คืนระบบด้วยเครื่องมือ System Restore
แนวคิดการสำรองข้อมูลตามมาตรฐาน 3-2-1 Backup Rule (ทำสำเนา 3 ชุด, เก็บ 2 รูปแบบสื่อ, เก็บไว้คนละสถานที่ 1 ชุด)
การตรวจสอบและเปิดใช้งาน System Protection สำหรับไดร์ฟระบบ (Drive C:)
การสร้างจุดกู้คืนระบบ (Create a Restore Point) ด้วยตนเอง
ขั้นตอนการเรียกใช้ System Restore เพื่อย้อนกลับระบบเมื่อเกิดปัญหาหน้าเครื่อง
การเข้าถึงหน้าต่าง Advanced Startup Options เพื่อกู้คืนระบบในกรณีที่บูตเข้า Windows ไม่ได้
สัปดาห์ที่ 15: การวิเคราะห์โจทย์และวางแผนขั้นตอนการทำโปรเจครายวิชา
การตีความเงื่อนไขและสถานการณ์จำลองในการกู้ชีพคอมพิวเตอร์
การแบ่งหน้าที่การทำงานระหว่างคู่บัดดี้ (คนปฏิบัติงานหน้าเครื่อง และคนจดบันทึก/วางแผน)
การเขียนผังงาน (Flowchart) สรุปลำดับขั้นตอนการซ่อมบำรุงระบบปฏิบัติการ
การลิสต์รายชื่อเครื่องมือหรือยูทิลิตี้ทั้งหมดที่จำเป็นต้องใช้ในภารกิจ
การประเมินความเสี่ยงและกำหนดแผนสำรองหากเกิดข้อผิดพลาด
สัปดาห์ที่ 16: การลงมือปฏิบัติงานโปรเจครายวิชาเพื่อแก้ปัญหาตามสถานการณ์จำลอง
การลงมือปรับแต่งระบบปฏิบัติการตามแผนเพื่อดึงประสิทธิภาพเครื่องสูงสุด (Performance Optimization)
การตั้งค่าความปลอดภัยของระบบและการจัดทำจุดสำรองข้อมูล
การรับมือและการใช้เครื่องมือกู้คืนระบบจากสถานการณ์ฉุกเฉินที่ครูจำลองขึ้น
การทดสอบการทำงานของเครื่องคอมพิวเตอร์หลังจากการกู้คืนสำเร็จ
การจดบันทึกขั้นตอนที่ทำสำเร็จและปัญหาที่พบระหว่างการปฏิบัติงานจริง
สัปดาห์ที่ 17: การนำเสนอผลงานโปรเจคหน้าชั้นเรียนและสรุปบทเรียนทั้งหมด
การจัดทำสรุปขั้นตอนการปฏิบัติงานเพื่อนำเสนอหน้าชั้นเรียน
เทคนิคการอธิบายวิธีการแก้ปัญหาทางเทคนิคให้เข้าใจได้ง่าย
การตอบคำถามและให้เหตุผลถึงการเลือกใช้โปรแกรมยูทิลิตี้แต่ละตัวในงาน
การวิเคราะห์ข้อผิดพลาดและสิ่งที่ได้เรียนรู้จากการลงมือปฏิบัติจริง
สรุปความรู้รวบยอดทั้งหมดของรายวิชา 31910-0001 ระบบปฏิบัติการและบำรุงรักษาคอมพิวเตอร์
