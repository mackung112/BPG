# Claude-Mem Skill Guide

คู่มือฉบับสรุปสำหรับการใช้งานชุดคำสั่งและสกิลจาก **[claude-mem](https://github.com/thedotmack/claude-mem)** ระบบสร้างความจำถาวร (Persistent Cross-Session Memory) และเครื่องมือสำรวจบริบทสำหรับ AI Coding Agents

---

## 1. ปัญหาและแนวคิดของ Claude-Mem

ปัญหาใหญ่ที่สุดของ AI Agent คือ **"ความจำเสื่อมทุกครั้งที่เปิดเซสชันใหม่"** และ **"Context Window ล้นจนเบลอ"**:
- **Persistent Timeline**: บันทึกเหตุการณ์ การตัดสินใจ และสิ่งที่เคยลองทำแล้วพัง เพื่อดึงกลับมาใช้ในเซสชันใหม่
- **Progressive Disclosure**: ค้นหาความจำแบบเปิดเผยทีละระดับ ไม่โหลดข้อมูลมหาศาลเข้ามาในคราวเดียว เพื่อประหยัดโทเคน

---

## 2. คลังคำสั่งและสกิลของ Claude-Mem

### 🧠 1. หมวดความจำและการสืบค้น (Memory & Context)
| สกิล | คำสั่งเรียกใช้ | หน้าที่และการใช้งาน |
| :--- | :--- | :--- |
| **Memory Search** | `/mem-search` | ค้นหาความจำ ข้อตกลง และประวัติการทำงานข้ามเซสชันในอดีต |
| **Smart Explore** | `/smart-explore` | สำรวจโครงสร้างโค้ดแบบประหยัดโทเคนด้วย Tree-sitter AST (แทนการเปิดอ่านทั้งไฟล์) |
| **Learn Codebase** | `/learn-codebase` | สั่งให้ Agent อ่านและทำความเข้าใจ Codebase ทั้งหมดเพื่อเตรียมความพร้อม |
| **Mem Handoff** | `/mem-handoff` | สร้างไฟล์ `HANDOFF.md` สรุปสถานะงาน สิ่งที่ลองแล้วพัง และ Next Steps เพื่อส่งต่อเซสชัน |
| **Cloud Sync** | `/cloud-sync` | สำรองข้อมูลและซิงก์ความจำขึ้น Cloud (cmem.ai Pro) |

  > `/timeline-report สรุปเส้นทางการพัฒนาโปรเจกต์นี้ทั้งหมดออกมาเป็นรายงาน`
