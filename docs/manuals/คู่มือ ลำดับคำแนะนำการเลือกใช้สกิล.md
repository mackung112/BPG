# คู่มือเปรียบเทียบสกิลที่ทับซ้อนกัน และลำดับคำแนะนำในการเลือกใช้
*(Skill Comparison & Recommendation Priority Guide)*

เอกสารฉบับนี้จัดทำขึ้นเพื่อแก้ปัญหา **"มีสกิลซ้ำซ้อนหรือทำหน้าที่คล้ายกันหลายตัว จะเลือกตัวไหนก่อน-หลัง?"** โดยรวบรวมตารางเปรียบเทียบสกิลที่มีหน้าที่ทับซ้อนกัน และฟันธง **ลำดับคำแนะนำ (Priority Order: อันดับ 1, อันดับ 2, อันดับ 3)** พร้อมแนบลิงก์ตรงไปยังไฟล์ของทุกสกิล เพื่อให้คุณหยิบไปใช้กับโปรเจกต์อื่นได้ทันทีโดยไม่ต้องตั้งค่าหรือคิดลำดับใหม่

## 🎯 สรุปสูตรสำเร็จพกพา (The Golden Rules Cheat-Sheet)

เมื่อนำชุดสกิลนี้ไปใช้ในโปรเจกต์อื่น ให้จำสูตรง่ายๆ ดังนี้:

```text
1. วางแผน/แตกตั๋วงาน    ➔ ยึด /to-spec + /to-tickets (Matt Pocock)
2. เขียนโค้ดอย่างมีสติ   ➔ ยึด /karpathy-guidelines + /implement + /tdd
3. มาตรฐานเฉพาะภาษา    ➔ ดึง [ภาษา]-patterns ของ ECC
4. เจอบั๊กยาก          ➔ ยึด /diagnosing-bugs (เทสต์ให้แดงก่อนแก้)
5. สไลด์และไดอะแกรม     ➔ สไลด์ใช้ /ppt-master | ไดอะแกรมใช้ /diagram-design
6. ส่งต่องานข้ามเซสชัน   ➔ ใช้ /mem-handoff (บันทึกสิ่งที่ลองแล้วพัง)
```
