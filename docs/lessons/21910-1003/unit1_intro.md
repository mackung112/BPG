### 🎯 จุดประสงค์การเรียนรู้ประจำสัปดาห์
1. อธิบายความหมาย ความสำคัญ และองค์ประกอบพื้นฐานของภาษาคอมพิวเตอร์ได้อย่างลึกซึ้ง

### 📚 1.1 ทำไมมนุษย์ถึงต้องสร้าง "ภาษาคอมพิวเตอร์"?

#### 1.1.1 กำเนิดและปัญหาของ "สมองกล"
นักเรียนอาจจะเคยได้ยินคำว่า "คอมพิวเตอร์ฉลาดมาก" แต่ความจริงแล้ว คอมพิวเตอร์เป็นเพียงเครื่องจักรที่ "ซื่อตรงและทำตามคำสั่งได้เร็วมาก" ต่างหากครับ สมองประมวลผลของมัน (CPU) สร้างมาจากวงจรอิเล็กทรอนิกส์นับล้านๆ ตัว มันรับรู้สถานะไฟฟ้าได้เพียงแค่ 2 สถานะเท่านั้น คือ **ไม่มีกระแสไฟฟ้า (0)** และ **มีกระแสไฟฟ้า (1)** 

ลองจินตนาการดูนะครับว่า หากครูต้องการสั่งให้คอมพิวเตอร์บวกเลข 15 กับ 20 ครูอาจจะต้องป้อนรหัส `00001111 00010100` สลับไปมาด้วยสวิตช์ปิดเปิด ซึ่งในยุคแรกเริ่ม มนุษย์เราทำแบบนั้นจริงๆ ครับ! มันเป็นความเจ็บปวดอย่างมหาศาล เพราะมนุษย์ไม่ได้สื่อสารกันด้วยเลขศูนย์กับหนึ่ง การจะเขียนโปรแกรมสักโปรแกรมต้องใช้ความอดทนและความแม่นยำสูงมาก พิมพ์ 0 ผิดเป็น 1 ตัวเดียว โปรแกรมทำงานผิดพลาดทันที

**"ภาษาคอมพิวเตอร์ (Computer Language)"** จึงถือกำเนิดขึ้นมาเพื่อเป็น "สะพานเชื่อม" ระหว่างภาษาของมนุษย์ (เช่น ภาษาอังกฤษ) กับภาษาของเครื่องจักร (เลข 0 และ 1) หน้าที่ของมันคือการยอมให้มนุษย์เขียนคำสั่งด้วยคำที่มนุษย์อ่านรู้เรื่อง เช่น พิมพ์คำว่า `print("Hello")` แล้วเดี๋ยวจะมีกลไกนำคำเหล่านี้ไปแปลงเป็น `01001000...` ให้เครื่องจักรเข้าใจเองครับ

#### 1.1.2 ย้อนประวัติศาสตร์: ต้นกำเนิดโปรแกรมเมอร์
ถ้าเราพูดถึงการเขียนโปรแกรม เราจะไม่พูดถึงสองท่านนี้ไม่ได้เลยครับ:
- **Charles Babbage (บิดาแห่งคอมพิวเตอร์):** นักคณิตศาสตร์ชาวอังกฤษที่ออกแบบเครื่องจักรที่เรียกว่า *Analytical Engine* ซึ่งมีกลไกในการรับข้อมูลเข้า ประมวลผล และแสดงผลลัพธ์ ซึ่งเป็นแนวคิดต้นแบบของคอมพิวเตอร์ในปัจจุบัน (แม้ในยุคนั้นเครื่องจักรนี้จะสร้างไม่เสร็จสมบูรณ์ก็ตาม)
- **Ada Lovelace (โปรแกรมเมอร์คนแรกของโลก):** เธอคือสุภาพสตรีที่ฉลาดปราดเปรื่อง เธอได้ศึกษาเครื่อง Analytical Engine และตระหนักว่า เครื่องจักรนี้ไม่ได้ทำได้แค่คำนวณตัวเลขธรรมดา แต่มันสามารถประมวลผลสัญลักษณ์ต่างๆ ได้ เธอจึงได้เขียน "อัลกอริทึม (Algorithm)" ชุดแรกของโลกขึ้นมาเพื่อใช้กับเครื่องจักรนี้ โลกจึงยกย่องให้เธอเป็นโปรแกรมเมอร์คนแรกอย่างแท้จริง

#### 1.1.3 องค์ประกอบของภาษาคอมพิวเตอร์
การเรียนภาษาโปรแกรม ก็เหมือนการเรียนภาษาอังกฤษ ภาษาไทย หรือภาษาเกาหลีเลยครับ มันมีองค์ประกอบที่ตายตัวอยู่ 3 อย่างที่เราต้องทำความเข้าใจ:
1. **คำศัพท์และคำสงวน (Vocabulary & Keywords):** 
   ในภาษาอังกฤษมีคำศัพท์อย่าง eat, sleep, run ในภาษาคอมพิวเตอร์ก็มีคำศัพท์เฉพาะที่เรียกว่า *Keywords* เช่น `if`, `else`, `while`, `for`, `return` คำเหล่านี้ถูกระบบ "จอง" ไว้แล้ว นักเรียนไม่สามารถเอาคำพวกนี้ไปตั้งชื่อมั่วซั่วได้ครับ
2. **ไวยากรณ์ (Syntax):** 
   ถ้าภาษาอังกฤษคือเรื่องของ Grammar (Subject + Verb + Object) ไวยากรณ์ในโค้ดก็คือกฎการเขียนครับ เช่น ภาษา C สั่งให้จบประโยคต้องใส่เครื่องหมายอัฒภาค (Semicolon `;`) หรือภาษา Python สั่งว่าถ้าอยู่ภายใต้เงื่อนไขเดียวกันต้อง "เว้นวรรค (Indentation)" ให้ตรงกัน ถ้าเราเขียนไวยากรณ์ผิด คอมพิวเตอร์จะไม่พยายามเดาความหมายให้เรานะครับ มันจะหยุดทำงานและฟ้องข้อผิดพลาดที่เรียกว่า **Syntax Error** ทันที
3. **ความหมาย (Semantics):** 
   สิ่งนี้ลึกซึ้งที่สุดครับ บางครั้งเราเขียนโค้ดถูกต้องตามไวยากรณ์ทุกอย่าง คอมพิวเตอร์ไม่ฟ้อง Error เลย แต่พอกดรัน... ผลลัพธ์ดันออกมาผิด! นั่นเพราะ "ความหมายเชิงตรรกะ" ของเราผิดครับ เช่น เราต้องการหาพื้นที่สี่เหลี่ยม กว้างคูณยาว แต่เราดันไปเขียนสูตรเป็น กว้างบวกยาว (Width + Height) แบบนี้เรียกว่า **Logical Error** ซึ่งจับผิดยากที่สุด เพราะคอมพิวเตอร์ไม่รู้หรอกว่าความตั้งใจที่แท้จริงของเราคืออะไร

### 📚 1.2 วิวัฒนาการและระดับของภาษาคอมพิวเตอร์

กว่าจะมาเป็นภาษาที่เราพิมพ์กันง่ายๆ ทุกวันนี้ บรรพบุรุษนักพัฒนาต้องฝ่าฟันอะไรมาเยอะครับ ครูขอแบ่งยุคของภาษาคอมพิวเตอร์ตาม "ระดับความใกล้ชิด" กับมนุษย์ ดังนี้:

#### 1.2.1 ภาษาระดับต่ำ (Low-Level Language)
นี่คือภาษาที่ "เครื่องรัก แต่มนุษย์เกลียด" ครับ เพราะมันใกล้ชิดกับฮาร์ดแวร์มากที่สุด
- **ภาษาเครื่อง (Machine Language / 1GL):** 
  คือยุคที่ 1 ของจริง ประกอบด้วย 0 และ 1 (Binary) ข้อดีข้อเดียวของมันคือ **ทำงานได้เร็วที่สุดแบบทะลุขีดจำกัด** เพราะเครื่องไม่ต้องแปลอะไรเลย รับปุ๊บทำปั๊บ แต่ข้อเสียคือมนุษย์แทบจะเขียนโปรแกรมที่ซับซ้อนไม่ได้เลย
- **ภาษาแอสเซมบลี (Assembly Language / 2GL):** 
  ยุคที่ 2 มนุษย์เริ่มทนไม่ไหว จึงมีการนำตัวอักษรภาษาอังกฤษมาทำเป็นตัวย่อ (Mnemonic Codes) แทนกลุ่มของรหัส 0, 1 เช่น ใช้คำว่า `ADD` แทนการบวก `MOV` แทนการย้ายข้อมูล และใช้โปรแกรมที่ชื่อว่า **Assembler** ในการแปลตัวย่อเหล่านี้กลับไปเป็น 0,1 อีกที แม้จะง่ายขึ้น แต่คนเขียนก็ต้องมีความรู้เรื่องโครงสร้างของ CPU (Registers, Memory Addresses) อย่างลึกซึ้ง ปัจจุบันภาษานี้ยังใช้เขียนตัวขับเคลื่อนฮาร์ดแวร์ (Driver) หรือระบบสมองกลฝังตัว (IoT) ที่ต้องการความเร็วสูงสุดครับ

#### 1.2.2 ภาษาระดับสูง (High-Level Language / 3GL)
ยุคที่ 3 นี่คือ "ยุคทองของการเขียนโปรแกรม" ครับ ภาษาระดับสูงถูกออกแบบมาให้ไวยากรณ์มีความใกล้เคียงกับภาษาอังกฤษและสูตรคณิตศาสตร์ที่มนุษย์คุ้นเคย เช่น การใช้คำสั่ง `print()`, `if (score > 50)`, `while (running == true)` 
ตัวอย่างภาษาในกลุ่มนี้ที่โด่งดังระดับโลก ได้แก่ **C, C++, Java, Python, JavaScript** 
ข้อดีคือโปรแกรมเมอร์ไม่ต้องปวดหัวเรื่องฮาร์ดแวร์ หรือการจัดสรรหน่วยความจำแบบลึกซึ้งอีกต่อไป โฟกัสไปที่ "อัลกอริทึมและการแก้ปัญหา" ได้เต็มที่เลยครับ (วิชาที่เรากำลังเรียนก็อยู่ในระดับนี้แหละครับ)

#### 1.2.3 ภาษายุคใหม่ (4GL และ 5GL)
- **ยุคที่ 4 (4GL - Very High-Level Language):** 
  ภาษายุคนี้เปลี่ยนแนวคิดจากคำถามที่ว่า "จะทำอย่างไร (How to do)" ไปเป็น "อยากได้อะไร (What to do)" ครับ ตัวอย่างที่ชัดเจนที่สุดคือภาษา **SQL (Structured Query Language)** ที่ใช้จัดการฐานข้อมูล เราแค่พิมพ์คำสั่งว่า "ขอดึงชื่อและนามสกุลของนักเรียนที่สอบได้เกรด 4" ระบบจะไปค้นหามาให้เอง โดยที่เราไม่ต้องเขียนโค้ดวนลูปทีละบรรทัดเพื่อค้นหาเลยครับ
- **ยุคที่ 5 (5GL - Natural Language & AI):** 
  เป็นยุคของการเขียนโปรแกรมเชิงตรรกะ (Logic Programming) เพื่อการพัฒนาระบบปัญญาประดิษฐ์ (AI) และระบบผู้เชี่ยวชาญ (Expert System) เช่น ภาษา **PROLOG** และ **LISP** เราจะไม่ได้สั่งงานเป็นขั้นเป็นตอน แต่เราจะป้อน "ข้อเท็จจริง (Facts)" และ "กฎเกณฑ์ (Rules)" ให้คอมพิวเตอร์ แล้วให้คอมพิวเตอร์ใช้วิจารณญาณในการอนุมานหาคำตอบด้วยตัวมันเองครับ

### 📚 1.3 ล่ามแปลภาษา: ศึกระหว่าง Interpreter vs Compiler

เมื่อเราเขียนโค้ดด้วยภาษาระดับสูง (เราเรียกโค้ดต้นฉบับนี้ว่า **Source Code**) คอมพิวเตอร์จะยังนำไปรันไม่ได้ทันทีครับ มันต้องการกลไกในการ "แปล" ให้เป็นภาษาเครื่องก่อน ในโลกของการเขียนโปรแกรม มีนักแปลอยู่ 2 สำนักใหญ่ๆ ที่ทำงานต่างกันสิ้นเชิง ครูอยากให้พวกเราทำความเข้าใจตรงนี้ให้ดีครับ เพราะมันส่งผลถึงการเลือกใช้ภาษาให้เหมาะกับโปรเจกต์เลยทีเดียว

#### 🎭 แบบที่ 1: อินเทอร์พรีเตอร์ (Interpreter) - "ล่ามแปลสดเฉพาะกิจ"
**หลักการทำงาน:** ลองนึกภาพนักเรียนไปฟังการสัมมนาของวิทยากรชาวต่างชาติ แล้วมี "ล่าม (Interpreter)" ยืนอยู่ข้างๆ วิทยากรพูด 1 ประโยค ล่ามก็แปลให้เราฟัง 1 ประโยค ทำแบบนี้ไปเรื่อยๆ จนจบการบรรยาย
ในทางคอมพิวเตอร์ Interpreter จะอ่าน Source Code ของเราจากบนลงล่าง **"ทีละบรรทัด"** อ่านบรรทัดแรกเสร็จ แปลเป็นภาษาเครื่อง แล้วสั่ง CPU ทำงานทันที จากนั้นค่อยไปอ่านบรรทัดที่สอง... ทำแบบนี้ไปเรื่อยๆ จนจบไฟล์

- **ข้อดีที่เหนือกว่า:** หากวิทยากรพูดผิด (เราพิมพ์โค้ดผิด) ล่ามจะหยุดชะงักและแจ้งเตือนเราทันทีในบรรทัดนั้น! นี่คือสวรรค์ของโปรแกรมเมอร์มือใหม่ครับ เพราะมันทำให้การหาจุดผิด (Debugging) ทำได้ง่ายมากๆ รันปุ๊บ รู้ปั๊บว่าพังตรงไหน
- **ข้อจำกัด:** เพราะต้อง "แปลไป รันไป" ทุกครั้งที่เรียกใช้งานโปรแกรม มันจึงทำงานได้ **ช้ากว่า** และผู้ใช้โปรแกรมของเราก็จำเป็นต้องติดตั้งตัว Interpreter ไว้ในเครื่องของเขาด้วย ถึงจะรันโปรแกรมเราได้ครับ
- **ภาษาที่ใช้สำนักนี้:** Python, JavaScript, PHP, Ruby

#### 📚 แบบที่ 2: คอมไพเลอร์ (Compiler) - "นักแปลหนังสือสุดเนี้ยบ"
**หลักการทำงาน:** ลองนึกภาพแฮร์รี่พอตเตอร์เล่มภาษาอังกฤษ สำนักพิมพ์จะไม่จ้างคนมานั่งแปลให้เราฟังทีละหน้าตอนเราซื้อไปอ่านใช่ไหมครับ? แต่สำนักพิมพ์จะจ้างนักแปลให้แปลรวดเดียวทั้งเล่มให้จบ พิมพ์ออกมาเป็นเล่มภาษาไทย (ไฟล์ .exe) แล้วค่อยวางขาย เราซื้อไปอ่าน (รันโปรแกรม) ได้ทันทีโดยไม่ต้องพึ่งนักแปลอีกแล้ว
Compiler ก็เช่นกันครับ มันจะอ่าน Source Code ของเราตั้งแต่บรรทัดแรกยันบรรทัดสุดท้ายแบบ **"รวดเดียวทั้งไฟล์"** แล้วทำการวิเคราะห์ ปรับแต่ง (Optimize) จากนั้นสร้างไฟล์ผลลัพธ์ที่เป็นภาษาเครื่อง (Object Code หรือ Executable File เช่น `.exe` บน Windows) ออกมาให้เรานำไปใช้งานได้เลย

- **ข้อดีที่เหนือกว่า:** ความเร็วครับ! เพราะโปรแกรมถูกแปลเตรียมไว้หมดแล้ว ตอนที่ผู้ใช้นำไปเปิดรัน คอมพิวเตอร์ไม่ต้องเสียเวลาแปลอะไรอีกเลย ทำงานได้ไหลลื่นรวดเร็วสุดๆ และผู้ใช้ไม่ต้องติดตั้ง Compiler ในเครื่องอีกต่อไป
- **ข้อจำกัด:** เป็นฝันร้ายของมือใหม่นิดๆ ครับ เพราะถ้านักเรียนพิมพ์ผิด (Syntax Error) แม้แต่เครื่องหมายคอมมา `,` หายไปตัวเดียว Compiler จะปฏิเสธการแปลทั้งไฟล์ทันที! มันจะฟ้อง Error ออกมาเป็นพรืด และบังคับให้เราแก้ให้ถูกต้องสมบูรณ์ 100% ก่อน ถึงจะยอมสร้างไฟล์ .exe ให้เราครับ
- **ภาษาที่ใช้สำนักนี้:** C, C++, Go, Rust

*(ข้อสังเกตจากครู: ในยุคปัจจุบัน มีภาษาอย่าง Java และ C# ที่ใช้เทคนิคแบบลูกผสม คือใช้ Compiler แปลรอบแรกลงมาเป็นภาษากลางที่เรียกว่า Bytecode ก่อน แล้วใช้ Interpreter ทำหน้าที่แปลง Bytecode ไปรันบนเครื่องเป้าหมายอีกที เพื่อดึงข้อดีของทั้งสองระบบมาใช้ครับ)*

### 📚 1.4 ทำไมโลกยุคนี้ถึงหลงรัก "Python"?

นักเรียนอาจจะสงสัยว่า ในเมื่อโลกนี้มีภาษาโปรแกรมเป็นร้อยภาษา แล้วทำไมทุกวันนี้ไม่ว่าจะไปที่ไหน บริษัทเทคโนโลยีไหนๆ มหาวิทยาลัยใดๆ ถึงบังคับให้เราเรียน Python? ทำไมวิชานี้ถึงไม่สอนภาษา C++ หรือ Java เหมือนสมัยก่อน? จากประสบการณ์ของครู นี่คือเวทมนตร์ของ Python ที่ทำให้มันครองโลกครับ:

#### 1.4.1 ปรัชญาแห่งความเรียบง่าย (Zen of Python)
ภาษา Python ถูกสร้างขึ้นมาโดยคุณ **Guido van Rossum** (โปรแกรมเมอร์ชาวดัตช์) ในปี ค.ศ. 1991 โดยมีปรัชญาหลักคือ **"รหัสโปรแกรม ควรอ่านง่ายเหมือนอ่านภาษาอังกฤษ"** 
ในภาษาอื่น ถ้านักเรียนอยากจะพิมพ์ข้อความทักทายออกทางหน้าจอ อาจจะต้องเขียนโค้ดที่มีโครงสร้างซับซ้อนถึง 5-6 บรรทัด มีวงเล็บเต็มไปหมด แต่ใน Python เราต้องการใช้แค่:
`print("Hello, World!")`
จบครับ! บรรทัดเดียวตรงๆ สั้น กระชับ และได้ผลลัพธ์ทันที

#### 1.4.2 กฎเหล็กแห่งการย่อหน้า (Indentation as Rule)
นี่คือฟีเจอร์ที่ครูรักที่สุดในการใช้ Python สอนเด็กๆ ครับ ในภาษาดั้งเดิมอย่าง C หรือ Java เราจะใช้ **"วงเล็บปีกกา { }"** ในการครอบชุดคำสั่ง (Block) ซึ่งทำให้นักพัฒนาบางคนเขียนโค้ดสะเปะสะปะ ไม่ยอมเว้นวรรคย่อหน้าให้เป็นระเบียบ พอครูมาตรวจโค้ดนี่ตาลายเลยครับ!
แต่ Python จัดการปัญหาโดยการ **ยกเลิกวงเล็บปีกกาทิ้งไปเลย!** แล้วบังคับให้โปรแกรมเมอร์ใช้ **"การเว้นวรรค (Indentation)"** หรือการกดปุ่ม Tab ในการจัดกลุ่มคำสั่งแทน ถ้าใครเว้นวรรคไม่ตรงกัน Python จะถือว่าคุณทำผิดไวยากรณ์และฟ้อง Error ทันที (IndentationError)
ฟีเจอร์นี้เป็นการบังคับให้ผู้เขียนโค้ดทุกคนบนโลก ต้องเขียนโค้ดออกมาอย่างเป็นระเบียบและอ่านง่ายในมาตรฐานเดียวกันครับ!

#### 1.4.3 ห้องสมุดที่กว้างใหญ่ที่สุดในโลก (Massive Ecosystem & Libraries)
Python มีแนวคิดที่เรียกว่า *"Batteries Included"* คือมันมาพร้อมกับโมดูลและคลังคำสั่ง (Library) พื้นฐานที่ครอบคลุมงานเกือบทุกประเภท ยิ่งไปกว่านั้น ชุมชนนักพัฒนา Python (Community) ใหญ่มาก หากนักเรียนต้องการทำงานพิเศษอะไรก็ตาม เช่น:
- **อยากทำ AI หรือ Data Science:** มีคนสร้างไลบรารี `TensorFlow`, `Pandas`, `NumPy` ไว้ให้เรียกใช้แล้ว
- **อยากสร้างเว็บไซต์:** มี `Django`, `FastAPI` ที่ดึงไปใช้สร้างเว็บระดับโลกได้เลย
- **อยากดึงข้อมูลจากเว็บอัตโนมัติ (Web Scraping):** มี `BeautifulSoup` หรือ `Selenium` ไว้ให้

นี่แหละครับ ความลับที่ว่าทำไม **Instagram, Spotify, Netflix, YouTube หรือแม้แต่ NASA** ถึงเลือกใช้ Python ขับเคลื่อนระบบเบื้องหลังขององค์กร!

### 📚 1.5 เตรียมเครื่องมือและสร้างโลกใบใหม่ (Installation & IDE)

เอาล่ะครับ เมื่อเราเข้าใจภาคทฤษฎีทั้งหมดแล้ว ถึงเวลาสวมวิญญาณโปรแกรมเมอร์และเตรียมอาวุธให้พร้อมรบ เราจะต้องติดตั้งเครื่องมือ 2 ส่วนหลักๆ ลงในเครื่องคอมพิวเตอร์ของเราครับ:

#### อาวุธชิ้นที่ 1: "สมองของงู" (Python Interpreter)
อย่างที่เราเรียนไปในสัปดาห์ที่ 1 ว่า Python เป็นภาษาประเภท Interpreter ดังนั้นคอมพิวเตอร์ของเราจะไม่รู้จักคำสั่ง Python เลยจนกว่าเราจะติดตั้งล่ามแปลภาษาลงไปครับ
1. ให้นักเรียนเปิดเบราว์เซอร์ไปที่เว็บไซต์ **[python.org/downloads](https://www.python.org/downloads/)**
2. ระบบจะวิเคราะห์ว่าเราใช้ Windows หรือ macOS ให้นักเรียนกดดาวน์โหลดเวอร์ชันล่าสุดได้เลย (แนะนำเวอร์ชัน 3.10 ขึ้นไป)
3. ⚠️ **จุดเป็นจุดตาย (ย้ำ 3 รอบ!):** เมื่อเปิดโปรแกรมติดตั้งขึ้นมา ในหน้าจอแรกสุด ด้านล่างของหน้าต่างจะมีกล่องกาเครื่องหมาย (Checkbox) เล็กๆ ที่เขียนว่า **`[x] Add Python 3.x to PATH`** 
   - นักเรียน **ต้องติ๊กถูกที่กล่องนี้เสมอ!** ก่อนที่จะกด Install Now
   - *สาระจากครู:* "PATH" คือสารบบของระบบปฏิบัติการ (Windows) การติ๊กช่องนี้คือการบอก Windows ว่า "เฮ้! เวลาฉันพิมพ์คำว่า python ในหน้าต่างคำสั่งดำๆ (Command Prompt) ขอให้แกลิงก์มาเรียกโปรแกรมตัวนี้ให้ทำงานหน่อยนะ" ถ้าเราลืมติ๊ก คอมพิวเตอร์จะฟ้องว่า 'python' is not recognized และเราต้องมานั่งแก้ Environment Variables กันยาวเลยครับ

#### อาวุธชิ้นที่ 2: "สมุดจดโค้ดระดับเทพ" (IDE / Code Editor)
แม้เราจะพิมพ์โค้ด Python ลงใน Notepad ธรรมดาแล้วนำไปรันได้ แต่คนฉลาดเขาไม่ทำกันครับ! เราต้องมีเครื่องมือทุ่นแรงที่เรียกว่า **IDE (Integrated Development Environment)** โปรแกรมเหล่านี้จะช่วยไฮไลต์สีคำสั่งแยกตามประเภท (ทำให้ดูง่าย), มีระบบเติมคำอัตโนมัติ (Auto-complete), และช่วยตรวจจับคำผิดให้เราก่อนรันจริง
- **สำหรับผู้ที่เพิ่งเริ่มต้นแบบสุดๆ:** ครูแนะนำ **Thonny** ครับ เพราะมันออกแบบมาให้มีหน้าตาคลีนๆ เรียบง่าย มีตัวรัน Python ฝังมาในตัวเลย โหลดมาเปิดปุ๊บ ใช้ได้ปั๊บ
- **สำหรับผู้ที่อยากไปสู่ระดับมืออาชีพ (มาตรฐานวิชานี้):** เราจะใช้ **Visual Studio Code (VS Code)** จากค่าย Microsoft ครับ
  - โหลด VS Code ได้ที่ `code.visualstudio.com`
  - เมื่อติดตั้งเสร็จ ให้เปิดโปรแกรม ไปที่แถบเมนูด้านซ้ายสุดคลิกไอคอนรูปบล็อก 4 เหลี่ยม (Extensions)
  - พิมพ์ค้นหาคำว่า `Python` (ผู้พัฒนาคือ Microsoft) แล้วกดปุ่ม **Install**
  - แค่นี้ VS Code ของเราก็พร้อมจะกลายเป็นสุดยอดอาวุธสำหรับเขียนโปรแกรมแล้วครับ!

นี่คืองานชิ้นแรกที่จะพิสูจน์ว่าระบบสภาพแวดล้อม (Environment) ในคอมพิวเตอร์ของนักเรียนพร้อมสำหรับการเรียนตลอดทั้งเทอมนี้แล้วหรือไม่ ให้นักเรียนปฏิบัติตามภารกิจต่อไปนี้อย่างเคร่งครัด:

1. **ภารกิจที่ 1 (ตั้งค่าระบบ):** 
   - ทำการดาวน์โหลดและติดตั้งตัวแปลภาษา Python ลงในเครื่องคอมพิวเตอร์ให้สมบูรณ์ (อย่าลืมติ๊ก Add to PATH)
   - ดาวน์โหลดและติดตั้ง Visual Studio Code (VS Code) พร้อมติดตั้งส่วนขยาย Python Extension

2. **ภารกิจที่ 2 (ทดสอบสมองงู):** 
   - เปิดหน้าต่าง **Command Prompt** (สำหรับ Windows) หรือ **Terminal** (สำหรับ Mac)
   - พิมพ์คำสั่ง `python --version` แล้วกด Enter
   - แคปเจอร์ (Screenshot) หน้าต่างผลลัพธ์ที่แสดงเลขเวอร์ชันของ Python ส่งเป็นหลักฐานรูปที่ 1

3. **ภารกิจที่ 3 (ก้าวแรกของโปรแกรมเมอร์ - The Hello World!):** 
   - เปิดโปรแกรม VS Code ขึ้นมา สร้างโฟลเดอร์สำหรับเก็บงานวิชานี้ (เช่น `Python_Class`)
   - สร้างไฟล์ใหม่โดยตั้งชื่อไฟล์ว่า `my_first_code.py` (จุดสำคัญคือต้องมีนามสกุล `.py` เสมอ)
   - พิมพ์คำสั่ง 3 บรรทัดด้านล่างนี้ลงในไฟล์ (ระวังการพิมพ์เครื่องหมายคำพูดให้ถูกต้อง):
     ```python
     print("Hello, World!")
     print("สวัสดีครับ/ค่ะ ครูแม็ค!")
     print("ผม/หนูชื่อ (พิมพ์ชื่อและนามสกุลตัวเอง) พร้อมรันวงการ Python แล้วครับ!")
     ```
   - สั่งรันโปรแกรมใน VS Code (กดปุ่ม Play มุมขวาบน)
   - แคปเจอร์หน้าจอโปรแกรมที่แสดงโค้ดและผลลัพธ์ (Output) ด้านล่าง ส่งเป็นหลักฐานรูปที่ 2

*"นักเรียนรู้ไหมครับว่า ทำไมโปรแกรมแรกในชีวิตของโปรแกรมเมอร์ทุกคนบนโลกใบนี้ ถึงต้องบังคับให้พิมพ์คำว่า Hello, World! ออกมา? ... ธรรมเนียมนี้ถูกสร้างขึ้นตั้งแต่ปี ค.ศ. 1978 โดย Brian Kernighan ผู้แต่งหนังสือสอนภาษา C ครับ มันไม่ได้แค่ทดสอบการพิมพ์อักษรท่องจำ แต่มันเป็นการทดสอบว่า 'ระบบและคอมพิวเตอร์ของคุณ' สื่อสารกับคุณสำเร็จแล้วต่างหาก! ... แล้วเจอกันในบทหน้านะครับพวกเรา ลุย!"*
