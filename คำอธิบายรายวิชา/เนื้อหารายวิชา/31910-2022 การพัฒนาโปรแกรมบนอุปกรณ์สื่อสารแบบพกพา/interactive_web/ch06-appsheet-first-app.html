MODULE 1: ARCHITECTURE & CLOUD ENGINE

1. รู้จัก Google AppSheet: เปลี่ยนสเปรดชีตให้เป็นแอปมือถือใน 30 วินาที

ในบทที่ 5 เราได้เนรมิตพิมพ์เขียวฐานข้อมูลบน Google Sheets ไว้ตามกฎเหล็ก 5 ประการอย่างสมบูรณ์แบบ ทั้งการกำหนด Primary Key การตั้งค่า Data Validation และการแปลงลิงก์รูปภาพ ในบทเรียนนี้คือช่วงเวลาที่น่าตื่นเต้นที่สุดของการเรียนรู้: "การแปลงข้อมูลตารางสเปรดชีตเหล่านั้น ให้กลายเป็นแอปพลิเคชันมือถือที่ใช้งานได้จริงบนสมาร์ตโฟน!"

1.1 Google AppSheet คืออะไร? และทำงานอย่างไร?

Google AppSheet เป็นแพลตฟอร์มการพัฒนาซอฟต์แวร์แบบ No-Code (ไม่ต้องเขียนโค้ดภาษาโปรแกรมแม้แต่บรรทัดเดียว) ที่ถูกเข้าซื้อและพัฒนาต่อโดย Google Cloud มีจุดเด่นเชิงวิศวกรรมที่ทรงพลัง 4 ประการ:

☁️ ทำงานร่วมกับ Google Workspace 100%

เชื่อมต่อตรงกับ Google Sheets เพื่ออ่าน-เขียนฐานข้อมูล อ่านรูปภาพจาก Google Drive ส่งอีเมลแจ้งเตือนผ่าน Gmail และสร้างเอกสารผ่าน Google Docs โดยไม่ต้องเขียน API

📱 Cross-Platform อัตโนมัติในคลิกเดียว

สร้างครั้งเดียว ใช้งานได้ทันทีบน iPhone (iOS), Android สมาร์ตโฟน, แท็บเล็ต iPad, และหน้าจอคอมพิวเตอร์ (Web Browser) โดยระบบจะปรับขนาดและ Layout ให้เหมาะสมตามอุปกรณ์

🎓 เปิดใช้งานฟรีเพื่อการศึกษาและต้นแบบ

สามารถสร้าง ทดสอบ และใช้งานระบบต้นแบบ (Prototype) ได้ฟรีโดยไม่มีค่าใช้จ่าย รองรับผู้ร่วมทดสอบในบัญชี Google ได้สูงสุด 10 คนต่อแอปพลิเคชัน

⚡ Offline-First พร้อมระบบ Live Sync

แม้เน็ตหลุดหรืออยู่ในพื้นที่ไม่มีสัญญาณ แอปยังเปิดดูแคตตาล็อกและบันทึกข้อมูลได้ เมื่อเชื่อมต่อเน็ตได้อีกครั้ง ระบบจะส่งข้อมูลไปซิงก์กับ Google Sheets บนคลาวด์อัตโนมัติ

MODULE 2: DATABASE LINKING

2. สองวิธีในการสร้างแอป AppSheet จาก Google Sheets

ผู้เรียนสามารถเลือกสร้างแอปพลิเคชันขึ้นมาได้จาก 2 เส้นทางหลัก ซึ่งทั้งสองวิธีจะนำพามาสู่ AppSheet Studio เหมือนกัน แต่มีความสะดวกและขั้นตอนที่แตกต่างกันเล็กน้อย:

วิธีที่ 1 (แนะนำ: เร็วและง่ายที่สุด) ⏱️ ใช้เวลา 15 วินาที

สร้างโดยตรงจากหน้า Google Sheets

เหมาะอย่างยิ่งสำหรับการเริ่มต้นโปรเจกต์ใหม่ เพราะระบบจะเลือกไฟล์สเปรดชีตปัจจุบันให้โดยอัตโนมัติ ไม่ต้องค้นหาไฟล์ในไดรฟ์

1 เปิดไฟล์ Google Sheets ของกลุ่มที่ทำไว้ในบทที่ 5 (เช่น Group03_FreshBrew_Database)
2 ที่แถบเมนูด้านบน คลิกที่คำว่า "ส่วนขยาย (Extensions)"
3 เลื่อนเมาส์ไปที่หัวข้อ "AppSheet"
4 คลิกคำว่า "สร้างแอป (Create an app)"
✓ ระบบจะเปิดแท็บใหม่ อ่านโครงสร้างตาราง และเนรมิตหน้าจอมือถือจำลองให้ทันที!
วิธีที่ 2 (แบบมาตรฐานผ่านเว็บหลัก) ⏱️ ใช้เวลา 45 วินาที

สร้างผ่านเว็บไซต์ AppSheet.com

เหมาะสำหรับกรณีต้องการสร้างแอปจากเทมเพลต หรือต้องการรวมแหล่งข้อมูลหลายแหล่งเข้าด้วยกันภายหลัง

1 เปิดเว็บเบราว์เซอร์ เข้าเว็บไซต์ www.appsheet.com
2 คลิก "Sign In" มุมขวาบน -> เลือก "Google" (ใช้อีเมลเดียวกับ Drive)
3 ที่แถบซ้าย คลิกปุ่ม "+ Create" -> "App" -> "Start with existing data"
4 ตั้งชื่อแอปในช่อง App name (เช่น Fresh Brew Delivery) และเลือก Category
5 คลิก "Choose your data" -> ค้นหาและเลือกไฟล์ชีตของกลุ่มจาก Google Drive
มิติการเปรียบเทียบ วิธีที่ 1: ผ่านเมนูส่วนขยายในชีต วิธีที่ 2: ผ่านเว็บไซต์ AppSheet.com
ความเร็วในการเริ่มต้น ⚡ เร็วมาก (คลิกเดียวเข้าสู่ระบบทันที) ต้องค้นหาโฟลเดอร์ใน Google Drive
โอกาสเลือกไฟล์ผิดพลาด แทบเป็นศูนย์ (เชื่อมตรงกับไฟล์ที่เปิดอยู่) อาจเผลอเลือกเวอร์ชันเก่าหากมีชื่อซ้ำกัน
การตั้งชื่อแอปเริ่มต้น ใช้ชื่อไฟล์ Google Sheets เป็นชื่อแอป สามารถตั้งชื่อแอปใหม่ได้ตั้งแต่ขั้นตอนสร้าง
ความเหมาะสม เหมาะสำหรับผู้เริ่มต้น & คลาสปฏิบัติการ 4 ชม. เหมาะสำหรับผู้ดูแลระบบหรือสร้างแอปที่ซับซ้อน

MODULE 4: DATABASE SCHEMA INTEGRITY

4. สองเช็กบ็อกซ์วิเศษ: Key [✓] และ Label [✓] (หัวใจสำคัญที่สุดของ AppSheet!)

ก่อนจะไปแต่งหน้าตาแอปให้สวยงาม ขั้นตอนที่สำคัญที่สุดและเป็น "เส้นแบ่งระหว่างแอปทำงานได้สมบูรณ์ กับแอปที่พังจนข้อมูลสูญหาย" คือการทำความเข้าใจและกำหนด 2 เช็กบ็อกซ์นี้ในหน้า Data -> Columns ให้ถูกต้อง:

ช่องที่ 1: Key [✓] (Primary Key) คอมพิวเตอร์ใช้อ้างอิง

รหัสพิกัดประจำแถว (ห้ามซ้ำและห้ามเปลี่ยน)

คือคอลัมน์ที่ระบบ AppSheet Cloud ใช้เป็น "ตัวระบุเอกลักษณ์ประจำแถว" เพื่อให้รู้ว่ากำลังอ่านหรือแก้ไขข้อมูลแถวไหน

📌 กฎเหล็กของ Key:
  • ใน 1 ตาราง ต้องมี Key ได้ เพียง 1 คอลัมน์เท่านั้น
  • ข้อมูลในคอลัมน์ Key ห้ามซ้ำกันเด็ดขาด (Unique Value)
  • เมื่อสร้างข้อมูลแล้ว ห้ามแก้ไขค่าในคีย์หลัก
  • ตัวอย่างที่ดี: Product_ID, Order_ID, Asset_ID
ช่องที่ 2: Label [✓] (Display Header) ตามนุษย์มองเห็น

ชื่อสื่อความหมายที่แสดงบนหน้าจอ

คือชื่อหัวเรื่องที่ "ตามนุษย์ใช้อ่านและเข้าใจ" เพื่อสื่อความหมายเมื่อไปปรากฏในรายการดรอปดาวน์หรือหัวข้อการ์ด

📌 กฎเหล็กของ Label:
  • ใน 1 ตาราง ควรมี Label ได้ เพียง 1 คอลัมน์เท่านั้น
  • เมื่อตารางอื่นอ้างอิงถึงข้อมูลนี้ (Ref) AppSheet จะดึงค่าในช่อง Label ไปแสดงให้คนอ่านรู้เรื่อง
  • ค่าในช่อง Label สามารถซ้ำกันได้ตามธรรมชาติของชื่อสินค้า
  • ตัวอย่างที่ดี: Product_Name, Service_Name, Asset_Name
ข้อควรระวังอันตรายถึงชีวิต (Fatal Mistake!):

ห้ามติ๊กช่อง Key [✓] ที่คอลัมน์ราคา (Unit_Price) หรือคอลัมน์รูปภาพเด็ดขาด! เพราะหากสินค้า 2 ชิ้นมีราคาเท่ากัน เช่น 55 บาททั้งคู่ AppSheet จะเข้าใจผิดว่าสินค้า 2 ตัวนี้คือชิ้นเดียวกัน และจะทำการ "เขียนทับข้อมูลจนหายนะ"! ให้ติ๊ก Key ที่รหัสประจำตัวของแถวนั้น เช่น Product_ID เท่านั้น!

MODULE 5: DATA TYPES & CURRENCY SETUP

5. การปรับแต่งชนิดข้อมูล (Data Types) ให้ตรงตามฟังก์ชันจริง

เมื่อเชื่อมต่อ Google Sheets ในตอนแรก AppSheet จะพยายามเดาชนิดข้อมูลให้โดยอัตโนมัติ แต่บ่อยครั้งที่ระบบเดาผิดพลาด เช่น มองราคาเป็นตัวเลขธรรมดา หรือมองรูปภาพเป็นข้อความยาว ดังนั้นนักพัฒนาต้องเข้าไปปรับแต่งใน Data -> Columns -> ตาราง Products ให้แม่นยำ:

ชื่อคอลัมน์ Type ที่ต้องปรับ Key [✓] Label [✓] ขั้นตอนการตั้งค่าเพิ่มเติมที่ต้องทำใน AppSheet
Product_ID Text ✓ − ติ๊กถูกช่อง Key [✓] และช่อง Require? [✓] (ห้ามว่าง)
Product_Name Text − ✓ ติ๊กถูกช่อง Label [✓] และติ๊กช่อง Search? [✓] (เพื่อให้ค้นหาชื่อสินค้าได้)
Category_Name Enum − − คลิกดินสอ [✎] ที่หัวข้อ Values เพิ่มรายการ: ชานม, กาแฟ, ขนม
Unit_Price Price − − คลิกดินสอ [✎] เลื่อนลงมาที่ช่อง Currency symbol เปลี่ยนจาก $ เป็น ฿ (ทศนิยม 2 ตำแหน่ง)
Stock_Qty Number − − กำหนด Minimum value = 0 (ป้องกันสต็อกสินค้าติดลบ)
Image_URL Image − − สำหรับดึงรูปภาพขนาดใหญ่จาก Google Drive มาแสดงเป็นภาพปก
Description LongText − − สำหรับข้อความบรรยายสรรพคุณ รายละเอียดวัตถุดิบ ความยาวหลายบรรทัด
Is_Available Yes/No − − สวิตช์เปิด/ปิด สถานะพร้อมจำหน่าย (Initial Value: TRUE)
วิธีเปลี่ยนสกุลเงินเป็นบาท (฿) อย่างละเอียด:

1. คลิกรูปดินสอ [✎] หน้าคอลัมน์ Unit_Price  •  2. เลื่อนลงมาที่หัวข้อ "Type Details"  •  3. ในช่อง Currency symbol พิมพ์ ฿  •  4. กด Done & Save

MODULE 9: CONDITIONAL LOGIC & EXPRESSIONS

9. เทคนิคขั้นสูง: การใช้สูตร Show_If ควบคุมการแสดงผล (Show_If Expressions)

ใน AppSheet เราสามารถควบคุมการ "ซ่อนหรือแสดง" คอลัมน์ ปุ่มกด หรือหน้าจอ ได้อย่างยืดหยุ่นด้วยสูตรตรรกะในช่อง Show_If (ถ้าสูตรคำนวณได้ TRUE จะแสดงผล ถ้าได้ FALSE จะซ่อนอัตโนมัติ):

1. แสดงเฉพาะในมุมมอง Card View
=CONTEXT("View") = "Products_Card"

ซ่อนฟิลด์ไม่ให้รกในตารางอื่น แต่ให้แสดงเด่นชัดเมื่ออยู่ในหน้า Card View

2. แสดงเฉพาะสินค้าที่พร้อมจำหน่าย
[Is_Available] = TRUE

ซ่อนสินค้าที่ปิดการขายชั่วคราว ไม่ให้ปรากฏให้ลูกค้ากดสั่งซื้อ

3. ซ่อนปุ่มสั่งซื้อเมื่อของหมดสต็อก
[Stock_Qty] > 0

ป้องกันลูกค้าสั่งซื้อเกินจำนวนที่มีในคลังสต็อก

4. แสดงราคาทุนเฉพาะแอดมิน
USEREMAIL() = "admin@freshbrew.com"

ซ่อนข้อมูลความลับทางการค้า เช่น ต้นทุนสินค้า ไม่ให้พนักงานทั่วไปมองเห็น

5. แสดงรูปภาพเฉพาะเมื่อมีลิงก์รูป
ISNOTBLANK([Image_URL])

ป้องกันการแสดงกรอบรูปภาพเปล่าหรือสัญลักษณ์ตกใจเมื่อสินค้ายังไม่มีรูป

6. อนุญาตให้ยืมเฉพาะอุปกรณ์ที่สถานะว่าง
[Current_Status] = "Available"

ใช้ในระบบ Smart Equipment เพื่อไม่ให้ผู้ใช้กดยืมอุปกรณ์ที่ถูกยืมไปแล้ว

2. เปิดแอป AppSheet ขึ้นมา แตะปุ่ม "Sign in with Google"
3. ล็อกอินด้วยอีเมล Google บัญชีเดียวกับที่ใช้สร้างไฟล์ในคอมพิวเตอร์
4. จะพบชื่อแอปของกลุ่มตนเองปรากฏในแท็บ "Owned by me" แตะเปิดแอปใช้งานได้ทันที!

MODULE 12: COLLABORATION MATRIX

12. การทำงานร่วมกันในทีม 3 คน (Collaboration Matrix)

การพัฒนาแอปพลิเคชันอย่างมืออาชีพต้องอาศัยการแบ่งบทบาทที่ชัดเจน ตารางความรับผิดชอบของสมาชิกทั้ง 3 คนในทีมสำหรับสัปดาห์ที่ 6 มีดังนี้:

บทบาทสมาชิก ตำแหน่งหน้าที่ ภารกิจที่ต้องส่งมอบในบทที่ 6
สมาชิกคนที่ 1 App Creator & Data Lead 1. เชื่อมต่อ Google Sheets เข้าสู่ AppSheet Studio
2. ตรวจสอบความถูกต้องของ Key [✓] และ Label [✓]
3. กำหนด Data Types (Price ฿, Image, Enum, Number) ให้สมบูรณ์
สมาชิกคนที่ 2 UX Designer & View Specialist 1. สร้างมุมมอง Card View และ Gallery View สำหรับแคตตาล็อก
2. ผูกรูปภาพ หัวข้อ ราคา และคำอธิบายลงในการ์ด
3. จัดกลุ่มหมวดหมู่ (Group by) และเรียงลำดับราคา (Sort by)
สมาชิกคนที่ 3 Tester & QA Lead 1. ติดตั้ง AppSheet บนสมาร์ตโฟนจริงและล็อกอินบัญชี Google
2. ดำเนินการทดสอบระบบ Live Sync แก้ไขข้อมูลชีตเทียบกับมือถือ
3. แชร์สิทธิ์ผู้ใช้งาน (Share app) และคัดลอกลิงก์ส่งงาน
MODULE 13: TROUBLESHOOTING & FAQS

13. ปัญหาที่พบบ่อยและวิธีแก้ไข (Troubleshooting & FAQs)

สาเหตุหลัก 2 ประการ:

  • สาเหตุที่ 1: สิทธิ์ในโฟลเดอร์ Google Drive ยังเป็นแบบ Private (ล็อกไว้) -> วิธีแก้: ไปที่ Drive คลิกแชร์โฟลเดอร์ เปลี่ยนเป็น "ทุกคนที่มีลิงก์มีสิทธิ์ดู (Anyone with the link)"
  • สาเหตุที่ 2: รูปแบบลิงก์ไม่ใช่ Direct Link -> วิธีแก้: แปลงลิงก์ให้อยู่ในฟอร์แมต https://drive.google.com/uc?export=view&id=FILE_ID ตามสูตรในบทที่ 5

สาเหตุ: ลืมติ๊กเลือกคอลัมน์ที่เป็น Key ในเมนู Data -> Columns

วิธีแก้: เข้าไปที่ Data -> Columns -> ตาราง Products -> ติ๊กเครื่องหมายถูกในช่อง Key [✓] ที่คอลัมน์ Product_ID จากนั้นคลิกปุ่ม 💾 Save ที่มุมบนขวา

วิธีแก้: ไปที่ Data -> Columns -> คลิกรูปดินสอ [✎] หน้าคอลัมน์ Unit_Price -> เลื่อนลงมาที่หัวข้อ Type Details -> ช่อง Currency symbol ให้พิมพ์ ฿ หรือ THB แล้วกด Done -> Save

วิธีแก้: แตะที่ ไอคอนลูกศรหมุนวน (Sync Button) ที่มุมขวาบนของหน้าจอมือถือ หรือปัดนิ้วลงเพื่อดึงรีเฟรชหน้าจอ (Pull to refresh) ข้อมูลจะอัปเดตเป็นค่าล่าสุดทันที

วิธีแก้: ต้องเพิ่มอีเมล Google ของเพื่อนในเมนู Share มุมขวาบนของ AppSheet Studio เสียก่อน หากไม่ได้ใส่อีเมลไว้ ระบบความปลอดภัยจะไม่อนุญาตให้เปิดแอป

วิธีแก้: ตรวจสอบการตั้งค่า Position ของ View นั้น หากตั้งเป็น ref หรือ menu จะไม่แสดงบนแถบเมนูด้านล่าง ให้เปลี่ยนค่า Position เป็น primary หรือ first
