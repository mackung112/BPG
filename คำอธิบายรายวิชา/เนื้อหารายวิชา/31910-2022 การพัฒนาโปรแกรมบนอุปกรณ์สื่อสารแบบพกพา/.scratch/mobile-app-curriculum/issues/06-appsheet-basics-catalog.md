# 06: AppSheet Mobile App Creation & Catalog Views

**What to build:** แนะนำการเชื่อมต่อ Google Sheets เข้าสู่ AppSheet เป็นครั้งแรก การตั้งค่า Table Mapping และการออกแบบหน้าจอแสดงผลแคตตาล็อกสินค้าในรูปแบบ Card View และ Gallery View บนสมาร์ตโฟนจริง

**Blocked by:** 05: Google Sheets Relational Database Architecture

**Status:** resolved

## Acceptance Criteria
- [x] เชื่อมต่อไฟล์ Google Sheets เข้าสู่ AppSheet สำเร็จโดยไม่มี Error
- [x] ตั้งค่าคอลัมน์ Label และ Image ได้ถูกต้อง
- [x] สร้างและปรับแต่งมุมมอง UX View แบบ Card View และ Gallery View ได้สมบูรณ์
- [x] ครอบคลุมการแสดงผลข้อมูลจริงของทั้ง 3 รูปแบบธุรกิจ (Archetypes)
- [x] มีขั้นตอนการติดตั้ง AppSheet Mobile App และเปิดดูข้อมูลบนสมาร์ตโฟนจริง
- [x] มีแบบตรวจสอบตนเอง (Self-Checklist) และเกณฑ์การประเมิน 10 คะแนน (Rubric)
