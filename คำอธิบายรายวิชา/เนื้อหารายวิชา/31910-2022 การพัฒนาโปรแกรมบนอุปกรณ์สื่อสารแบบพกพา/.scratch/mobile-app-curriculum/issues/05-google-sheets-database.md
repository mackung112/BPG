# 05: Google Sheets Relational Database Architecture

**What to build:** ออกแบบและจัดทำโครงสร้างฐานข้อมูลเชิงสัมพันธ์บน Google Sheets ครอบคลุม 3 รูปแบบธุรกิจ (สินค้า/บริการ/คลัง) พร้อมกำหนด Primary Key, Foreign Key, Data Types และข้อมูลตัวอย่าง 15 รายการ เพื่อเตรียมพร้อมเชื่อมต่อ AppSheet

**Blocked by:** 04: Interactive Mobile Prototyping & Smartphone Testing

**Status:** resolved

## Acceptance Criteria
- [x] มีตารางโครงสร้างข้อมูลอย่างน้อย 4 ตารางต่อธุรกิจ (เช่น สินค้า, หมวดหมู่, ลูกค้า, คำสั่งซื้อ)
- [x] ระบุชนิดข้อมูล (Data Types) และคีย์หลัก (Key Column) ของทุกคอลัมน์อย่างแม่นยำ
- [x] ปราศจากช่องว่างในหัวคอลัมน์ (Column Naming Best Practices)
- [x] มีข้อมูลตัวอย่างที่สมบูรณ์อย่างน้อย 15 แถว พร้อมใช้งานจริง
- [x] มีแบบตรวจสอบตนเอง (Self-Checklist) และเกณฑ์การประเมิน 10 คะแนน (Rubric)
