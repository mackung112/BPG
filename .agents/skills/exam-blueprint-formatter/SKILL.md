# คู่มือการจัดทำแนวข้อสอบฉบับย่อสำหรับ LINE

Skill นี้ช่วยให้ AI สามารถสรุปและจัดรูปแบบแนวข้อสอบหรือเนื้อหาความรู้ให้อยู่ในรูปแบบที่สั้น กระชับ และสวยงาม เหมาะสำหรับการก๊อปปี้ไปส่งในกลุ่มผู้เรียนบนแอปพลิเคชัน LINE ได้ทันที

## ขั้นตอนการทำงาน
1. **วิเคราะห์เนื้อหาต้นฉบับ:** อ่านเนื้อหาหรือไฟล์ข้อสอบ (เช่น txt, md, docx) ทั้งหมดที่ผู้ใช้ระบุ
2. **สรุปใจความสำคัญ:** ดึงมาเฉพาะหัวข้อหลัก ฟังก์ชันที่สำคัญ ปุ่มลัด และคีย์เวิร์ดที่มักจะออกสอบ
3. **จัดรูปแบบสำหรับ LINE:** 
   - ใช้สัญลักษณ์ เช่น `🔹`, `•`, `---` ในการแบ่งสัดส่วนและทำเป็น bullet points
   - ใส่อิโมจิที่สื่อถึงเนื้อหาหน้าหัวข้อหรือท้ายข้อความเพื่อความน่าสนใจ (เช่น 📚, 💻, 🎯, ✨)
   - ตัดทอนคำอธิบายที่ยืดเยื้อออก เน้นความสั้นและกระชับ
   - ใช้การเน้นคำด้วยตัวหนา (`**ข้อความ**`) สำหรับหัวข้อหลักหรือใจความสำคัญ
4. **บันทึกหรือแสดงผล:** ตอบกลับให้ผู้ใช้ก๊อปปี้ได้ง่ายๆ หรือบันทึกลงไฟล์ที่กำหนด
