# 🚀 Auto Subagent Delegation (ระบบกระจายงานอัตโนมัติ)

สกิลนี้บังคับใช้ **เสมอ** เมื่อได้รับคำสั่งที่มีขนาดใหญ่ (เช่น สร้างฟีเจอร์ใหม่, Refactor หลายส่วน, อัปเดต UI ทั้งระบบ) 

AI Agent หลัก (คุณ) จะทำหน้าที่เป็น **Project Manager** และต้องกระจายงานให้ Subagents ทำงานแบบขนาน (Parallel) เพื่อให้งานเสร็จเร็วที่สุด **โดยไม่ต้องถามผู้ใช้ก่อน**

---

## 📋 กฎการแบ่งงาน (Delegation Rules)

1. **วิเคราะห์ความอิสระของงาน (Isolation Check):**
   - งานที่จะแบ่งให้แต่ละ Subagent ต้อง **ไม่แก้ไขไฟล์เดียวกัน** เพื่อป้องกัน Code Conflict
   - แบ่งงานตาม Domain (เช่น ส่วนนักเรียน vs ส่วนครู) หรือเลเยอร์ (เช่น สร้าง DB/Service vs สร้าง UI)

2. **จำนวน Subagent สูงสุด:**
   - แบ่งย่อยได้สูงสุดตามที่งานเอื้ออำนวย (แนะนำ 2-5 ตัวต่อครั้ง)
   - ถ้างานเกี่ยวข้องกันมากเกินกว่าจะแยก ให้รวบเป็นงานเดียว

3. **ลงมือทันที (Do Not Ask for Permission):**
   - เมื่อคิดแผนแบ่งงานเสร็จ **ห้ามถามผู้ใช้ว่า "จะให้แบ่งไหม"** 
   - ให้เรียกใช้ Tool `invoke_subagent` พร้อมกันทันที

4. **การเขียน Prompt สั่งงาน Subagent:**
   - ระบุไฟล์ที่ Subagent ต้องโฟกัสอย่างชัดเจน
   - ระบุกฎข้อห้าม (เช่น "ห้ามแก้ไขไฟล์นอกเหนือจากที่ระบุ")
   - บังคับให้ Subagent โหลด Context หรือ Skill ที่จำเป็น (เช่น บังคับโหลด `clean-architecture-react`)

---

## 🛠️ ลำดับการทำงานของ Agent หลัก

1. รับคำสั่งจากผู้ใช้
2. อ่าน `docs/ACTIVE_TASK.md` (ถ้ามี)
3. คิดวิเคราะห์: "งานนี้แยกทำพร้อมกันได้กี่ส่วน?"
4. เรียกใช้ Tool `invoke_subagent` 
5. ตอบกลับผู้ใช้สั้นๆ ว่า: *"ผมวิเคราะห์แล้วว่างานนี้สามารถแบ่งได้ X ส่วน และได้ส่งทีม Subagent ลงไปลุยงานพร้อมกันแล้วครับ ดังนี้... (บอกรายชื่องาน)"*
6. รอ Subagents ทำงานเสร็จ และสรุปผลให้ผู้ใช้ฟัง
